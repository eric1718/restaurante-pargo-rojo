> **Sabores auténticos del Caribe colombiano.** Plataforma web comercial diseñada para la promoción gastronómica y la visualización interactiva del menú del Restaurante Pargo Rojo en Cartagena de Indias.

## 📖 Descripción del Proyecto

**Restaurante Pargo Rojo** es una page orientada a la atracción de turistas y locales interesados en la gastronomía marina tradicional de la región. La plataforma presenta un catálogo digital de platos típicos (pargo rojo frito, cazuelas de mariscos, ceviches, patacones), combinación visual atractiva y llamados a la acción para reservas directas.

## ✨ Características Principales

- 📱 **Diseño Responsivo (Mobile-First):** Visualización adaptada para móviles, tablets y computadores.
- 🍽️ **Menú Digital Interactivo:** Presentación clara de especialidades marinas, precios e ingredientes.
- 📸 **Enfoque Gastronómico:** Presentación de platillos con diseño visual optimizado para la conversión de clientes.
- 📍 **Ubicación y Contacto Directo:** Enlaces a canales de atención inmediata (WhatsApp / llamadas) para pedidos y reservas.
- 🚀 **Despliegue de Alta Velocidad:** Alojado en red CDN a través de Netlify para carga rápida.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Despliegue:** Netlify
* **Diseño:** UI/UX enfocado en el sector restaurante y conversión comercial.
